# How to work in this repo

CT (Christopher) owns this. Upload videos to a Google Drive folder, press a button, get a montage.

- **Keep it simple.** One file, `montage.py`. No settings. Add a feature only when CT asks.
- **Free.** No paid APIs. Any AI runs on CT's computer.
- **ffmpeg does the video work.** Google Drive for desktop does the syncing.
- **Never change the uploaded videos.** Write only to the `Montages` folder.
- **No em dashes.**
- Commits go to `main`, small, plain messages. Don't open or watch pull requests unless CT asks.
