# How to work in this repo

CT (Christopher) owns this. It is a small tool: folder of videos in, montage with text over it out.

- **Keep it simple.** One file, `montage.py`. Add a feature only when CT asks.
- **ffmpeg does the video work. Pillow draws the text.**
- **Never change the files in the user's folder.** Write only to `output/`.
- **No em dashes.**
- Commits go to `main`, small, plain messages. Don't open or watch pull requests unless CT asks.
